Manifesto

I start where the signal starts — at the board, the wire, the protocol — and follow it all the way to the screen.

Every project here follows the same five moves, and each move leaves a record.

  1. 01

    Observe

    Read the schematic before writing the spec. Hardware assumptions get checked early.

  2. 02

    Draft

    Write the protocol down and version it. Ask the teams you depend on for the smallest change.

  3. 03

    Build

    Build against a synthetic source, so missing hardware never blocks the pipeline.

  4. 04

    Ship

    Ship the core that holds, and name what was deferred as technical debt.

  5. 05

    Evidence

    Publish each claim with the record that backs it, or mark it as not yet measured.
